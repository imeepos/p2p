# 任务类型规范：调研（research）

目录：1. 何时打此标签 → 2. 任务书差异 → 3. 验收门 → 4. 高频坑 → 5. 深入阅读

## 1. 何时打此标签

技术选型、竞品与生态调研、陌生领域侦察、账本 Guesses 验真、决策依据搜集类任务。产出物是"可追溯来源支撑的临时判断"，不是可运行代码，也不是约束后续编码的 spec。执行方法论全文在 `references/research.md`（五层流程：问题定义 → 搜索策略 → 来源评估 → 证据综合 → 沉淀输出），执行会话按它跑；本文件只写派发差异与验收门。

与 architecture 的边界：research 产出"带证据链的判断"，architecture 产出"约束后续编码的 spec/ADR"。选型任务的正确切法是 research 出对比与置信度，决策与 ADR 归 architecture 或人——调研+提案打包一个任务是混类，拆开。

## 2. 任务书差异（在通用模板上追加）

- **问题定义先行**：任务书必须含可被证据推进的问题（"我正在研究 X，因为我想知道 Y，这样我就能帮助 Z"句式）+ 会改变判断的证据 + 最低可接受证据。写不出就回炉计划——禁止派"帮我了解一下 X"式漫游调研；最低可接受证据同时是停止条件（预算）。
- **双路径起步**：至少两条搜索路径（关键词 + 引用/脚注/作者/机构/争议任一）；只交单一来源汇总的是摘抄不是调研。
- **来源纪律**：关键说法必须能按 SIFT 追溯到原始语境；来源按使用等级标注；模型生成文本、无出处截图、营销汇编是不稳定来源，只可作线索入口，不可作证据。
- **反证义务**：必须记录反证与弃用来源及原因；禁止只收支持当前看法的材料。
- **结论强度 ≤ 证据强度**：结论必带置信度、未知项、下一步；它入账本只按 Guesses 待遇（带过期条件），禁止当 Facts 写进后续任务书。
- **产出物路径固定**：研究日志 + 证据矩阵 + 注释书目落盘到任务书指定路径（模板见 `research.md` §5），主控按路径机械验收。

## 3. 验收门（主会话机械核验）

- [ ] 产物首节呼应任务书的问题定义句与最低可接受证据
- [ ] 抽查 2 条关键说法：能沿标注追溯到原始来源（SIFT trace）
- [ ] 证据矩阵存在，且含至少一条反对/中性证据；只有支持材料的打回
- [ ] 结论带置信度与未知项；存在未处理的已知反证不验收
- [ ] 来源分级完成，无不稳定来源充当证据
- [ ] 未知项已转成账本 Guesses（带过期条件）或 TODO.md 条目

## 4. 高频坑与对策

| 坑 | 对策 |
| --- | --- |
| 无问题定义的漫游搜集，永不停止、产出大而空 | 任务书先钉问题 + 最低可接受证据（即停止条件） |
| 把摘录当理解、把首条高排名结果当结论 | 验收抽查 2 条说法的追溯链，追不到即打回 |
| 只找支持材料，调研变成立场辩护 | 反证与弃用来源是硬性产出，验收门核对 |
| 调研结论被当 Facts 直接派发 | 临时判断入账本一律 Guesses 待遇，过期条件从未知项导出 |
| 模型生成文本/截图被当稳定证据 | 不稳定来源只作线索入口，验收门核对来源分级 |
